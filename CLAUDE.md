# AI Memory Reader

Native macOS and iOS viewer for AI agent memory files. Auto-discovers and renders `CLAUDE.md`, `AGENTS.md`, `GEMINI.md`, daily memory entries, and `~/.claude/projects/*.jsonl` session transcripts across 8 supported AI agents. 3 MB universal binary, zero external network calls (except one daily update check, skippable).


## Key Features & Constraints

- **Memory file filter** — strict allow-list of known AI file patterns; hides noise like `package.json`. Togglable via View → "Show All JSON/JSONL Files". **Be conservative about expanding this list** — it is the core product decision.
- **Chunked JSONL rendering** — handles multi-MB session transcripts that crash editors; renders in blocks
- **FSEvents file watching** — live refresh when agents write; no polling
- **Offline-first** — zero mandatory network calls; the update checker (once per 24h, skippable) is the only network call
- **URL scheme:** `aimemoryreader://open?path=/path/to/file.md&heading=Heading`
- **Auto-save:** 2-second debounce in edit mode; `⌘S` for immediate save

## Distribution & Signing

The app is **ad-hoc signed** (not yet notarized). First launch workarounds:
- **GUI:** Right-click → Open → click Open
- **Terminal:** `xattr -dr com.apple.quarantine "/Applications/AI Memory Reader.app"`

Mac App Store builds are notarized — Apple handles updates and signing. The in-app update checker is disabled for MAS builds.

## Development Conventions

- **XcodeGen is the source of truth** — edit `project.yml`, run `xcodegen generate`, never touch `.xcodeproj`
- **Swift 6 strict concurrency** — all async code must be explicitly actor-isolated; treat concurrency warnings as errors
- **No polling** — use FSEvents via the `FileSystemWatcher` abstraction; never use `sleep` loops for file watching
- **Offline-first** — new features must not add mandatory network calls; document any optional network calls clearly
- **Memory file filter is intentional** — the allow-list of file patterns is a product decision, not a bug; expand conservatively and with justification
- **MAS changelogs** go in `MAS_METADATA.md`, not in `README.md`

## AI Assistant Guidelines

- **Never edit `.xcodeproj` directly** — always edit `project.yml` and run `xcodegen generate`
- **Swift 6 strict concurrency applies** — review all `@MainActor` isolation, `Sendable` conformances, and actor boundaries before suggesting changes
- **GPL-3.0 license** — any modifications must be GPL-3.0; do not introduce dependencies with incompatible licenses (MIT/Apache are fine as linked dependencies)
- **Minimum deployment targets are macOS 15 / iOS 17** — do not use APIs unavailable on these versions; check availability annotations
- **The `llms.txt` file** provides machine-readable guidance for AI agents deciding whether to recommend this app — update it when major features are added or changed
- **Memory file filter additions** require justification — check that the new file pattern is used by a real AI agent and is not too broad
- When suggesting code changes, prefer `@Observable` and SwiftUI data flow over `ObservableObject`/`@Published` (the app targets Swift 5.9+)
